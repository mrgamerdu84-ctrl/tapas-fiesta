# Politique de confidentialité — Tapas Fiesta

Dernière mise à jour : 3 septembre 2026

Tapas Fiesta respecte la vie privée de ses utilisateurs.

## Données personnelles

Dans la version actuelle de l’application :

- aucun compte utilisateur n’est demandé ;
- aucune donnée personnelle n’est transmise à un serveur par Tapas Fiesta ;
- les informations nécessaires au déroulement d’une partie sont traitées localement dans l’application ;
- aucune donnée personnelle n’est vendue à des tiers ;
- aucune fonctionnalité de publicité ou de suivi analytique n’est intégrée par Tapas Fiesta.

Si une future version ajoute une fonctionnalité nécessitant des données personnelles, cette politique devra être mise à jour et les utilisateurs devront en être informés clairement.
