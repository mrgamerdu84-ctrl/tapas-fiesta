# Branding officiel — Tapas Fiesta!

Ce dossier contient les deux visuels officiels choisis pour le jeu.

- `icon.png` : icône Android carrée « TF ».
- `splash.png` : image verticale « Tapas Fiesta! » utilisée pour l'écran de démarrage.

## Règle importante

Ne pas retoucher, recolorer, recadrer ou remplacer les images originales sans demande explicite.

Le workflow GitHub Actions peut créer automatiquement des copies techniques aux dimensions exigées par Android. Les fichiers originaux présents dans `resources/` restent inchangés.

Le projet reste prévu pour évoluer : le code du jeu, les sons et les futures fonctionnalités peuvent être modifiés indépendamment du branding.
